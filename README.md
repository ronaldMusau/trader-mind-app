# Trader Mind app

Ronald's phone dashboard: trades split into stocks, forex, commodities and crypto, demo-ticket approvals, and the daily journal.

This repo holds only the screens. All data lives in Supabase behind a login; sign-ups are off and the database rejects writes from the app, except Approve/Reject on a waiting demo ticket.

Install: open https://ronaldmusau.github.io/trader-mind-app on your phone, sign in, then Add to Home Screen.
